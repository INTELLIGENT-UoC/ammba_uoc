# Contributing

Contributions are welcome. The
[contributing guide](https://github.com/INTELLIGENT-UoC/ammba_uoc/blob/main/CONTRIBUTING.md)
describes the workflow: pull requests against `main`, Conventional Commits,
automated releases, and the licensing of contributions under
GPL-3.0-or-later. Each component's `AGENTS.md` describes its conventions and
typical changes in more detail, for human contributors and coding assistants
alike.

## Documentation

The documentation lives in `docs/` and is built with MkDocs and the Material
theme. Preview it locally with live reload:

```bash
uvx --with-requirements docs/requirements.txt mkdocs serve
```

Continuous integration builds the site with `mkdocs build --strict` whenever
the documentation changes; broken links, missing pages and unknown anchors fail
the build.

Conventions:

- Formulas use LaTeX between `$…$` for inline and `$$…$$` for display
  mathematics, which renders both on the site and on GitHub. Symbols follow the
  [notation](../model/notation.md) page.
- Links to files outside `docs/` use absolute GitHub URLs, because the site
  cannot resolve them.
- The figures in `docs/assets/figures/` are generated by `make_figures.py` in
  the same folder; regenerate them rather than editing the images:

```bash
uv run --no-project --with matplotlib --with numpy python docs/assets/figures/make_figures.py
```

When a change alters behaviour that the documentation describes, update the
affected pages in the same pull request.

## Reporting issues

Please report bugs and propose features as
[issues](https://github.com/INTELLIGENT-UoC/ammba_uoc/issues). For security
issues, follow the
[security policy](https://github.com/INTELLIGENT-UoC/ammba_uoc/blob/main/SECURITY.md).
